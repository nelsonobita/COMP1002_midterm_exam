# Mid term assignment

**Course:** COMP1002
**Author:** NelsonObita

## Description

A user registration form built with HTML5 and CSS3. Demonstrates semantic HTML structure, form validation, and CSS selector types.

## Files

| File | Description |
|------|-------------|
| `Midterm.html` | Registration form with Account Info and Preferences sections |
| `Midterm.css` | Stylesheet covering layout, form elements, and button styling |

## How to Open

Open `Midterm.html` directly in any modern web browser — no server or build step required.

## Features

- HTML5 form validation (required fields, minlength, email format)
- Two fieldsets: Account Info and Preferences
- Inputs: text, email, password, date, radio, select, checkbox
- CSS selector types: element, class, ID, attribute, pseudo-class
